1. Introduction to Python

Python is a programming language that is known for having simple and easy-to-read syntax. It is used for different types of projects such as websites, automation, data analysis, and software development.

Python is also commonly used when learning programming because its basic code is easy to understand.

2. Your First Python Program

One of the first things beginners learn is how to display text using the print() function. 

print("Hello, World!")

The text inside the quotation marks will be displayed when the program runs.

3. Variables

Variables are used to store information. A variable can contain text, numbers, or other types of data. 

name = "Gabriel"
age = 20

print(name)
print(age)

In this example, the variable name contains text while age contains a number.

4. Basic Data Types

Python has different types of data. Some basic examples are shown below.

Data Type Example Use

5. Basic Operators

Operators are used to perform calculations and other operations.

Operator Meaning Example
+ Addition 5 + 2

6. If and Else Statements

An if statement is used when a program needs to make a decision. The else statement can be used when the condition is not true. 

age = 18

if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

7. Loops

A loop is used when we want to repeat a piece of code. A simple example is a for loop. 

for number in range(5):
    print(number)

This example prints the numbers from 0 to 4.

8. Functions

A function is a block of code that can be reused. Functions are useful when the same task needs to be performed more than once. 

def greet():
    print("Hello!")

greet()

The def keyword is used to create a function.

9. Lists

A list can store multiple values in one variable. 

fruits = ["Apple", "Banana", "Mango"]

print(fruits[0])

Python starts counting list positions from 0, so fruits[0] gives the first item.
